# lh_rm2026_Sentry

重庆三峡学院 LionHeart 战队哨兵上位机框架。

本项目基于 ROS2 Humble 开发，定位于哨兵车上位机的整体软件框架，覆盖通信、决策、自瞄、仿真与工具链等内容。当前仓库以 ROS2 工作空间形式组织，源码和依赖主要位于 `new_dev/src` 下。

## 1. 项目简介

本仓库用于实现哨兵上位机的核心能力，包括：

- 底层串口通信与状态管理
- 任务决策与模式切换
- 目标识别、跟踪与自瞄控制
- 仿真调试、录包与机器人描述文件管理

## 4. 框架结构

仓库当前以 ROS2 工作空间组织，主干结构通常如下：

- `new_dev/src/camera`：相机相关功能包
- `new_dev/src/dependencies`：第三方或基础依赖包
- `new_dev/src/lh2025_robot_description`：机器人描述与 URDF 相关内容
- `new_dev/src/rmu_gazebo_simulator`：Gazebo 仿真相关内容
- `new_dev/src/tools/rosbag2_composable_recorder`：录包工具

其中，`dependencies` 下包含若干独立仓库或子模块式依赖，例如：

- `hik_camera_ros2_driver`
- `joint_state_publisher`
- `rmoss_core`
- `rmoss_gazebo`
- `sdformat_tools`

## 5. 功能说明

### 5.1 通信与系统管理

负责串口通信、全局消息、启动管理、看门狗等基础能力。

### 5.2 决策与任务调度

负责根据地图、状态与任务目标生成模式、路径和策略。

### 5.3 自瞄与视觉

负责图像处理、目标探测、跟踪与击打控制。

### 5.4 导航模块

导航模块目前已独立到 `2025_sentry_nav-main` 仓库中维护，本仓库主要负责与其集成、调用和配置。

其职责包括：

- 建图
- 定位
- 路径规划
- 导航状态管理

### 5.5 仿真与工具

负责机器人描述、Gazebo 仿真、录包与调试工具。

## 6. 通信方式

当前系统采用 UART 单串口通信，按任务进行分包互斥发送。

## 7. 配置方式

决策模块通常需要针对不同地图配置以下内容：

- 决策树
- 模式集
- 路径集

并在 `config.json` 中选择对应配置。
